# 🐺 নেকড়ে-গ্রাম (Nekregram) — v005

**Wolvesville-অনুপ্রাণিত একটি সম্পূর্ণ বাংলা সোশ্যাল ডিডাকশন মাল্টিপ্লেয়ার গেম।**
Node.js + Socket.io দিয়ে তৈরি — একই কোড LAN এবং ইন্টারনেট (অনলাইন) উভয় জায়গাতেই চলে।

**তৈরি করেছেন:** Kamrul Hasan Sabbir

## 🎮 গেমের বৈশিষ্ট্য

- ৮টি রোল: গ্রামবাসী, নেকড়ে মানব, গণক ঠাকুর (Seer), ডাক্তার, শিকারী (Hunter), ডাইনি বুড়ি (Witch), গ্রামপ্রধান (Mayor), পাহাড়াদার (Bodyguard)
- খেলোয়াড় সংখ্যা অনুযায়ী স্বয়ংক্রিয় রোল বণ্টন (৪–১৬ জন)
- সম্পূর্ণ দিন/রাত চক্র: রাত (গোপন অ্যাকশন) → দিন (আলোচনা) → ভোট (বহিষ্কার) → পুনরাবৃত্তি
- শিকারীর "শেষ প্রতিশোধ" মেকানিক — মারা গেলেও একজনকে সাথে নিয়ে যেতে পারে
- গণক ঠাকুর কাউকে যাচাই করলে, তার কার্ড বক্সেই কয়েক সেকেন্ডের জন্য রোল ইমোজি + নাম ভেসে ওঠে
- ডাক্তার নিজেকে সর্বোচ্চ একবার বাঁচাতে পারে — কার্ড কাউন্টার দিয়ে ট্র্যাক করা হয়
- গ্রামপ্রধান আলোচনার সময় নিজেকে প্রকাশ করে ভোটের ক্ষমতা দ্বিগুণ করতে পারে
- পাহাড়াদার প্রতি রাতে একজনকে রক্ষা করে, প্রয়োজনে নিজের জীবন উৎসর্গ করে
- রিয়েল-টাইম মাল্টিপ্লেয়ার (Socket.io) — রুম কোড দিয়ে যোগ দেওয়া যায়
- ইন-গেম চ্যাট ও ঘটনাপ্রবাহ লগ
- হোস্ট ডিসকানেক্ট হলে স্বয়ংক্রিয়ভাবে নতুন হোস্ট নির্বাচন
- মোবাইল ও ডেস্কটপ উভয় ক্ষেত্রেই পূর্ণ অপ্টিমাইজড রেসপনসিভ UI — Wolvesville-স্টাইল গ্রিড প্লেয়ার লেআউট (৪-১৬ জন পর্যন্ত স্বয়ংক্রিয়ভাবে স্কেল হয়)

### 🆕 v005-এ নতুন কী যোগ হলো

- **নির্মাতার ক্রেডিট ট্যাগ:** হোম স্ক্রিনের নিচে "Created by Kamrul Hasan Sabbir" — একটি স্টাইলিশ, সুষম আকারের ব্যাজ হিসেবে দেখা যায়।
- **সম্পূর্ণ ক্রস-ডিভাইস UI/UX অপ্টিমাইজেশন:** ডেস্কটপে মাল্টি-কলাম গ্রিড লেআউট (স্ট্যাটাস/গোরস্থান/লগ/চ্যাট পাশাপাশি) আরও কার্যকরভাবে জায়গা ব্যবহার করে; মোবাইলে টাচ-ফ্রেন্ডলি বাটন সাইজ, স্মুথ টাচ-স্ক্রলিং, নন-ক্লিপিং মডাল ডায়ালগ, ও নচ/হোম-ইন্ডিকেটর সেফ-এরিয়া সাপোর্ট যোগ হয়েছে।
- **রেসপনসিভ প্লেয়ার কার্ড:** স্ক্রিনের প্রস্থ অনুযায়ী কার্ড সাইজ রিসাইজে স্বয়ংক্রিয়ভাবে মানিয়ে নেয় (উইন্ডো রিসাইজেও)।
- সব গেম মেকানিক্স, রোল ক্ষমতা, দিন/রাত চক্র, ভোট ও Socket.io ইভেন্ট — সব স্ক্রিন সাইজে ১০০% অপরিবর্তিত ও যাচাইকৃত।

### v004-এ যা যোগ হয়েছিল

- **দিন/রাত ডায়নামিক থিম (Wolvesville-স্টাইল):** দিনের বেলা (আলোচনা + ভোট) UI স্বয়ংক্রিয়ভাবে উজ্জ্বল/হালকা থিমে বদলে যায় (গাঢ় কনট্রাস্ট টেক্সটসহ); রাতে গাঢ় থিম + হালকা টেক্সট ফিরে আসে।
- **টার্গেটেড ডেথ ব্লিংক:** কেউ মারা গেলে, শুধু সেই খেলোয়াড় নিজে ১-২ সেকেন্ডের ফুল-স্ক্রিন রেড ফ্ল্যাশ দেখে; বাকি সবাই শুধু তার কার্ড বক্সটি লাল ব্লিংক করতে দেখে।
- **স্থায়ী ক্রস (❌) চিহ্ন:** ব্লিংক শেষ হওয়ার পর, মৃত খেলোয়াড়ের কার্ডে বাকি ম্যাচের জন্য একটি স্থায়ী ক্রস চিহ্ন বসে যায়।
- **রোল গোরস্থান সাইডবার:** গেম স্ক্রিনে একটি নতুন "🪦 রোল গোরস্থান" প্যানেল যোগ হয়েছে, যা এই ম্যাচের সব রোল তালিকাভুক্ত করে এবং কোনো রোলের খেলোয়াড় মারা গেলে সেই রোলের একটি এন্ট্রিতে line-through বসিয়ে দেয়।
- উপরের সব ফিচারই স্বাভাবিক মাল্টিপ্লেয়ার ও ডেভেলপার/সোলো-টেস্ট (বট) মোড — উভয় ক্ষেত্রেই একইভাবে কাজ করে।

## 📦 ইনস্টলেশন

তোমার কম্পিউটারে [Node.js](https://nodejs.org) (v16 বা তার বেশি) ইনস্টল থাকতে হবে।

```bash
cd nekre-gram
npm install
npm start
```

সার্ভার চালু হলে টার্মিনালে দেখাবে:
```
নেকড়ে-গ্রাম সার্ভার চলছে! (Nekregram v005)
লোকাল: http://localhost:3000
```

ব্রাউজারে `http://localhost:3000` খুললেই গেম খেলা যাবে।

## 🏠 LAN-এ (একই WiFi/রাউটারে) খেলা

1. যে কম্পিউটারে সার্ভার চালু আছে, সেটির **লোকাল IP ঠিকানা** বের করো:
   - Windows: `ipconfig` (দেখো "IPv4 Address")
   - Mac/Linux: `ifconfig` অথবা `ip addr` (দেখো `192.168.x.x` বা `10.x.x.x`)
2. একই WiFi/রাউটারে থাকা অন্য যেকোনো ডিভাইস থেকে ব্রাউজারে যাও:
   `http://<সার্ভারের-IP>:3000` (যেমন: `http://192.168.1.12:3000`)
3. সবাই নাম দিয়ে রুম কোড ব্যবহার করে একই রুমে যোগ দাও। হোস্ট "খেলা শুরু করো" চাপলেই খেলা শুরু হবে।

> ফায়ারওয়াল যদি পোর্ট ৩০০০ ব্লক করে, সেটি সাময়িকভাবে খুলে দাও অথবা `server.js`-এ `PORT` পরিবর্তন করো।

## 🌍 ইন্টারনেটে (অনলাইনে) খেলা

সার্ভারটি যেকোনো Node.js হোস্টিং-এ ডিপ্লয় করা যায় — যেমন Render, Railway, Fly.io, বা নিজের VPS। ডিপ্লয়ের পর:

1. প্ল্যাটফর্মের দেওয়া পাবলিক URL-টি বন্ধুদের সাথে শেয়ার করো।
2. সবাই সেই URL-এ গিয়ে নাম দিয়ে রুম তৈরি/যোগ করবে — ঠিক LAN-এর মতোই, শুধু IP-এর বদলে ইন্টারনেট URL ব্যবহার হবে।

দ্রুত টেস্টের জন্য, নিজের কম্পিউটার সাময়িকভাবে ইন্টারনেটে এক্সপোজ করতে [ngrok](https://ngrok.com) ব্যবহার করতে পারো:
```bash
ngrok http 3000
```
এটি একটি অস্থায়ী পাবলিক URL দেবে যা LAN-এর বাইরের বন্ধুরাও ব্যবহার করতে পারবে।
